📌 Project Overview

This Industrial SCADA System is designed for real-time monitoring, control, and logging of process variables like temperature and pressure. It combines Modbus TCP communication with a Python Flask backend and a modern dark industrial frontend for seamless operations.

🛠 Technologies Used

  • Backend: Python (Flask), PyModbus, SQLite
  • Frontend: HTML5, CSS3, JavaScript, Chart.js
  • Communication: Modbus TCP/IP to PLCs

🎯 Key Features

  • Real-time line charts for temperature & pressure.
  • Historical data logging & CSV export.
  • Secure user authentication.
  • Industrial dark mode interface with animated glowing cards & buttons.
  • Flexible trend/log filters (1min, 1h, All).
  • Supports multiple PLCs and client connections.

🚀 Project Goals

  • Optimize industrial monitoring & control.
  • Provide intuitive, readable dashboards for operators.
  • Ensure data reliability & analysis readiness.
  • Enable scalability for additional process variables.

📖 Future Enhancements

  • Predictive analytics & alerts using AI/ML.
  • Alarms & notifications for abnormal conditions.
  • Responsive design for mobile devices.
  • Multi-language support for global deployment.
